# نظام التصميم — الصفوة

> المرجع البصري: لوحات SaaS حديثة (DocAnalise، FreshQuote على Dribbble) مُكيّفة لمكتب خدمات عربي: هادئة، موثوقة، واضحة، بدون زخرفة.

## المبادئ

1. **الثقة قبل الإبهار:** لا تدرجات لونية صاخبة، لا confetti، لا إيموجي، لا حركة نابضة على الشارات. ألوان قليلة بمعنى ثابت.
2. **"على مين الدور؟" في كل مكان:** كل معاملة تُظهر حالتها + الطرف المطلوب منه التحرك (المكتب/العميل/الجهة) + موعدها.
3. **اللون لا يكفي وحده:** كل حالة = لون + أيقونة + نص (WCAG 1.4.1).
4. **عربي أولًا:** RTL أصلي بخصائص منطقية (`ms-/me-/ps-/pe-/start/end`)، الأسهم الاتجاهية تنقلب تلقائيًا، أرقام لاتينية (0-9) متناسقة في كل الواجهة، وإدخال الأرقام العربية الهندية مقبول ويُحوَّل.
5. **إتاحة WCAG 2.2 AA:** تباين نص ≥ 4.5:1، مؤشر تركيز واضح، كل حقل له label وربط للخطأ، تنقل كامل بالكيبورد، احترام `prefers-reduced-motion`، رابط "تخطَّ إلى المحتوى".

|---|---|---|---|

| `ink / ink-2 / ink-3` | `#18201d / #444c48 / #646b67` | فاتح مقابل | النص الأساسي/الثانوي/الوصفي (كلها ≥ 4.5:1) |

| `info / success / warning / danger / violet / neutral` | دلالية | دلالية | الحالات والتنبيهات |

**ربط الحالات:** جديد/مراجعة = info · بانتظار العميل = warning · لدى الجهة/معاينة = violet · موافقة/جاهز = success · مرفوض = danger · مغلق/ملغي = neutral.

- **الخط:** IBM Plex Sans Arabic (400/500/600/700) مستضاف ذاتيًا — مصمم لواجهات البرمجيات، واضح في الأحجام الصغيرة، وله نظير لاتيني متناسق.
- **المقاسات:** نص أساسي 15px بارتفاع سطر 1.7، الجداول 14px، العناوين 24–28px (الموقع العام حتى 48px). لا نص عربي أقل من 12px.
- **الأبعاد:** شبكة 4px، حواف 8px للعناصر و12–16px للكروت، ظلال خفيفة جدًا.
- **الوضع الداكن:** مدعوم بالكامل عبر نفس الرموز.

## أنماط الشاشات

- **لوحة الموظفين:** شريط جانبي أبيض (يمين في RTL) بمجموعات، شريط علوي بالبحث الشامل (اختصار `/`) وزر "معاملة جديدة"، صفحة بعنوان ووصف وإجراءات.
- **تفاصيل المعاملة:** صفحة كاملة (وليست نافذة منبثقة) — تبويبات: الخطوات، المستندات، المالية، السجل؛ وعمود جانبي: "المطلوب الآن"، العميل، بيانات المعاملة، الموقف المالي، مرجع الإجراء.
- **الجداول:** رأس ثابت، صف قابل للنقر مع رابط حقيقي في أول خلية، أرقام بمحاذاة جدولية، حالة فارغة مفيدة.
- **الموقع العام:** بطل بعنوان واضح + نموذج تتبع سريع، خدمات حسب التصنيف، "كيف نعمل"، التزاماتنا، الفروع، أسئلة شائعة، وإخلاء مسؤولية "مكتب خاص وليس جهة حكومية" في التذييل والإيصالات.
- **الطباعة:** إيصال A5 بالتفقيط، وقائمة مستندات قابلة للطباعة لكل خدمة.
